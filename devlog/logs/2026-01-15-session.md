## Lessons Learned

### Niagara Parameter API (UE5.7)
1. **`SetNiagaraVariableFloat(FString)`** - DEPRECATED in 5.3, just wraps SetVariableFloat
2. **`SetVariableFloat(FName)`** - Recommended for setting, uses `SetVariable_Deferred`
3. **`GetVariableFloat(FName, bool&)`** - For reading values, returns value + validity flag
4. **"User." prefix is OPTIONAL** - `FNiagaraUserRedirectionParameterStore` auto-redirects both with and without prefix
5. **Changes are DEFERRED** - Stored in OverrideParameters, need `ReinitializeSystem()` to apply
